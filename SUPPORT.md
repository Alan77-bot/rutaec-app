# Soporte del proyecto — RutaEC

## Consultas y problemas

Las dudas técnicas, solicitudes de funcionalidades y errores del sistema deben registrarse mediante GitHub Issues.

Antes de crear un Issue, se recomienda verificar si existe otro relacionado con el mismo problema.

## Tipos de solicitudes

- **Tareas:** nuevas funcionalidades, mejoras o configuraciones.
- **Errores:** fallos encontrados durante el desarrollo o las pruebas.
- **Documentación:** aclaraciones o actualizaciones de las guías.

Cada Issue debe describir claramente la solicitud, su responsable y los criterios necesarios para comprobar su solución.

## Problemas de seguridad

Las vulnerabilidades y los incidentes relacionados con información sensible deben comunicarse de forma privada siguiendo `SECURITY.md`.

No deben publicarse credenciales ni datos personales como evidencia.

## Coordinación

El jefe del equipo organizará la asignación y el seguimiento de tareas junto con los demás integrantes.
